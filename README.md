Current repository for Davin Tipton's neutrino-driven wind evolution code. This code is in active development. 

INSTALLATION INSTRUCTIONS------------------------------------------------------

1. Clone the repository using the command: git clone --recursive https://github.com/Davint2136/nu_wind.git
2. Navigate to the PyCompOSE directory and install: pip install .
3. Navigate to the bns_nurates directory, generate the python bindings, and install via pip using [bns_nurates' instructions](https://github.com/RelNucAs/bns_nurates).
